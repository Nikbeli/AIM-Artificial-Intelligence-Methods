# Сегментация медицинских изображений с помощью метода Otsu и генетического алгоритма  

* Метод Otsu: метод глобального определения порога для сегментации изображений.  
* Генетический алгоритм (GA) - метод метаэвристической оптимизации, основанный на естественном отборе для улучшения процесса порогового отбора.
Гибридный метод обеспечивает лучшую сегментацию изображений с различным распределением контрастности и интенсивности, что часто наблюдается при медицинской визуализации.
