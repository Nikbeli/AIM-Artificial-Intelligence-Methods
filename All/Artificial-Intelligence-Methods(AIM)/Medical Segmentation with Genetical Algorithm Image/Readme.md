# Сегментация медицинских изображений с помощью метода Otsu и генетического алгоритма  

Jupyter Notebook демонстрирует сегментацию медицинских изображений мозга с использованием гибридного подхода, сочетающего метод пороговой обработки Otsu и генетический алгоритм (GA). Этот метод разработан специально для анализа медицинских изображений, чтобы повысить точность сегментации в сложных сценариях, таких как визуализация головного мозга.

> Сегментация медицинских изображений является важнейшим этапом анализа медицинских изображений, позволяющим идентифицировать и отделять интересующие области, такие как опухоли или повреждения, от окружающих тканей.

* Метод Otsu: метод глобального определения порога для сегментации изображений.  
* Генетический алгоритм (GA) - метод метаэвристической оптимизации, основанный на естественном отборе для улучшения процесса порогового отбора.
Гибридный метод обеспечивает лучшую сегментацию изображений с различным распределением контрастности и интенсивности, что часто наблюдается при медицинской визуализации.
