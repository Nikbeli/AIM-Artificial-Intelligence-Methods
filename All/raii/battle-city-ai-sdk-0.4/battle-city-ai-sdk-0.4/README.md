# Battle City AI - редакция "ЛШ РАИИ 2025"

В этом дистрибутиве находятся материалы для написания, запуска и проверки стратегий в рамках локальной игровой сессии.

Дистрибутив состоит из следующих папок:

* `game-session` - движок игровой сессии;
* `logs` - тут будет лог битвы для его визуализации;
* `maps` - карты для проверки стратегии в разных условиях;
* `strategy-csharp` - основа для разработки стратегии на C# (.NET 9);
* `strategy-python` - основа для разработки стратегии на Python;
* `visualizer` - небольшое приложение-визуализация игровой сессии.

## Как с этим работать?

Во-первых, надо выбрать основу для разработки.
Это может быть или C#, или Python.

Для C# необходимо установить пакет SDK для .NET 9.0 с сайта <https://dotnet.microsoft.com/ru-ru/download>.
Для Python достаточно установить python3.

Чтобы начать разрабатывать стратегию на C#, изменяйте файл `strategy-csharp\Strategy.cs`.
В Python - `strategy-python\src\strategy.py`.

В описании стратегии есть два метода:

* в первом приходит исходное состояние игрового поля: карта и точки спавна.
* второй метод принимает на вход состояние игрового мира и ожидает на выходе реакцию юнитов стратегии на внешний мир.

Чтобы запустить игровую сессию, надо:

* запустить файл `run game-session.bat`;
* запустить файл `run strategy-csharp.bat` или `run strategy-python.bat` в зависимости от типа стратегии;
* запустить ещё раз стратегию (свою или стандартную), т.к. игровая сессия подразумевает наличие двух стратегий;
* дождаться окончания игровой сессии;
* запустить визуализатор через `run visualizer.bat`;
* открыть файл с логом из `logs/` и нажать `Play`, потом `Next`.
